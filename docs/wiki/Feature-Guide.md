# Feature guide

| Workspace | What you can do |
| --- | --- |
| **Overview and Accounts** | View account summaries, refresh observed balances and stock, add or import accounts, organize groups, and save operation profiles. The desktop keeps saved sessions locally. A configured worker can receive the sessions needed for selected accounts. |
| **Automation** | Select accounts and enable case, virtual cash, and vault collection per account. Pause or resume individual accounts and see cooldown and request status. The optional server mode uses a verified SSH connection to your own worker. |
| **Open cases** | Browse the catalog and stock, choose accounts and quantities, inspect results, and use ordered keep, sell, or storage rules. Favorites and items with insufficient ranking evidence are protected when applying the relevant rules. |
| **Token converter** | Review which steps are available, including selling, buying or opening eligible converter capsules, converting stickers or items, and routing eligible results to a destination account. The review reflects account state and completed steps. |
| **Inventory and storage** | Switch accounts, filter or search skins, inspect float and attachments, browse storage, and review individual or batch actions. Review storage creation, renaming, clearing, and removal. View pending results and completed history. |
| **Games** | Open up to 20 account cards in the workspace. The game picker includes Blackjack, Coinflip, Jackpot, Case Battle, Crash, Upgrade, Dice, Plinko, and Guess the Rank. Individual game controls and observations vary by game and session. |
| **Rewards and skills** | Check reward, mission, and monthly-pass eligibility. Review eligible progression changes, inspect skill maps, and manage presets. |
| **Opening preferences** | Enable the optional page from Settings to review eligible game-side favorite and autosell preferences. Local opening rules are configured in Open cases. |
| **Diagnostics, Activity, and Settings** | Compare account observations, inspect request timing and outcomes, export persistent history, and configure appearance and available integrations. |

## Review and confirmation

A review records the intended accounts, items, and action. If the app shows **Unconfirmed**, check the operation’s state before starting anything that could repeat it. A missing response can occur after the site received the request. Expired or changed reviews require a new review for remaining items.

## Capabilities that need further verification

Selected-capsule opening is enabled with offline contract coverage. General collection opening, keychain collection opening, event-ticket opening and purchase, and boost activation are disabled while their request and result checks are incomplete. Settings shows the capability reasons. Offline tests cover simulated workflows and package startup. Live sign-in and site behaviour need separate validation.
