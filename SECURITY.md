# Security policy

## Reporting a vulnerability

Please report security issues **privately** using [GitHub Security Advisories](https://github.com/rowkavdev/AltCrate/security/advisories/new) for this repository (or the **Report a vulnerability** link on the Security tab). Do not open a public issue for exploitable or sensitive findings.

Include:

- A clear description of the issue and likely impact
- Steps to reproduce or a proof of concept, if possible
- Affected versions or commits, if known

We will acknowledge receipt and work with you on a fix and disclosure timeline when appropriate.

## Sensitive data in reports

**Never** include Case Clicker Online credentials in advisories, issues, pull requests, or CI logs, including:

- Cookies or session tokens
- Passwords or API keys
- Exported account data, vault contents, or other player-identifying material

Use synthetic fixtures, redacted screenshots, and local-only reproduction steps instead.

## Scope notes

AltCrate interacts with third-party game services. Reports about the game itself should go to the game operator unless they are introduced or worsened by AltCrate’s client or bundled engine behaviour.
